Final Segmentation and Morphology Output

Final Segmentation Result

The final result of the pipeline is a segmented microscopy image with detected cell boundaries drawn over the original image. This visualization shows where the program identified individual cell regions after color enhancement, thresholding, morphological cleanup, and watershed segmentation.

Final boundary overlay showing the detected cell regions from the segmentation pipeline.

Printed Output

After running measure_cells, the program prints the number of detected cells and a morphology table. The detected cell count is calculated after filtering out very small regions that are likely noise and very large regions that may represent merged objects or false detections.

The morphology table gives one row per detected cell. Each row represents a labeled region from the final watershed segmentation, and each column describes a different property of that cell.

Measurements Included

  • Label: the ID number assigned to each segmented cell.
  • Area: the number of pixels inside the detected cell region.
  • Perimeter: the length of the cell boundary.
  • Eccentricity: how elongated the cell is.
  • Solidity: how completely the cell fills its outer boundary.
  • Major axis length: the length of the longest axis through the cell.
  • Minor axis length: the length of the shortest axis through the cell.
  • Centroid: the approximate center location of the cell.
  • Mean intensity: the average purple/blue enhancement value inside the cell.
  • Circularity: a calculated measure of how round the cell is.
  • Aspect ratio: the ratio between the major and minor axis lengths.

Result Interpretation

These results show that the program does more than simply produce a binary mask. It converts the image into measurable information about each detected cell. The final boundary image helps visually inspect the segmentation, while the table provides quantitative data that can be used to compare cell size, shape, and structure.
